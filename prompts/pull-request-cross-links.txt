Each description names the PRD and links every other pull request opened for it, so once all are open, edit each to add the links. Where one must merge before another, for example an endpoint before the page that calls it, say so in each, as the technical design gives the order. Where they must merge in an order, end each description with the line `Merge order: N of M`, where N is its place and M the number of pull requests; a description without that line states no order, and its pull request can merge at any point.
