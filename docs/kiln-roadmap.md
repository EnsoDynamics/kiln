# Kiln roadmap

Ideas for future Kiln features. Each idea has a separate note with context for writing a PRD later.

| Idea | What it adds | Detail |
|---|---|---|
| Run a whole PRD roadmap | Carry a sequence of PRDs through their own audits and final delivery without a manual handoff between PRDs. | [Feature note](roadmap/kiln-whole-prd-roadmap-execution-idea.md) |
| Run independent phases in parallel | Run independent phases at the same time, with separate workspaces and safe integration. | [Feature note](roadmap/kiln-parallel-phase-execution-idea.md) |
| Computer-use preflight and Codex desktop handoff | Identify phases needing desktop apps and hand them to Codex desktop. | [Feature note](roadmap/kiln-desktop-computer-use-handoff-idea.md) |
| Review each phase before commit | Let a person review staged phase work before authorizing its commit. | [Feature note](roadmap/kiln-review-before-commit-idea.md) |
| Merge the final PR | Optionally carry final review PRs through checks and an authorized merge. | [Feature note](roadmap/kiln-final-pull-request-merge-idea.md) |
| Desktop app | Provide a native wrapper and PRD-folder drag and drop. | [Feature note](roadmap/kiln-desktop-app-idea.md) |
| A "why it stopped" headline | Generate a short explanation above the complete stop message. | [Feature note](roadmap/kiln-stop-reason-headline-idea.md) |
| A background service | Keep controllers running without an attached terminal. | [Feature note](roadmap/kiln-background-service-idea.md) |
| Ubuntu live messages and safe terminal takeover | Qualify live messages and safe takeover on Ubuntu, including remote tmux use. | [Feature note](roadmap/kiln-ubuntu-live-control-idea.md) |
| Notifications | Notify the person when work needs attention or is ready for review. | [Feature note](roadmap/kiln-system-notifications-idea.md) |
| A home screen | List and select PRDs from a browser or desktop entry screen. | [Feature note](roadmap/kiln-prd-home-screen-idea.md) |
| An end-of-PRD summary | Summarize interventions, session counts and unvalidated assumptions. | [Feature note](roadmap/kiln-end-of-prd-summary-idea.md) |

The [feature-note index](design/kiln-after-v1-ideas.md) retains older reference links. Detailed prose lives in the individual notes.
