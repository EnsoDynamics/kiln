Kiln Pause Now

Pause a running build at any moment, then resume it later or take the conversation over in your terminal.

Kiln can already stop a running build at a safe point and keep its conversation, but it calls that Pause & take over and lands on an amber Needs you page built around terminal instructions. This change renames it Pause now, shows what Kiln is waiting for while it pauses, and lands on a calm Paused page where Resume and the terminal command sit side by side. The pause after a phase changes only its label. As today, Pause now isn't offered for sessions run with Codex, or during the readiness check Kiln runs before the first phase or its final delivery step after the last.

01 / SECTION

While Kiln is pausing

Two moments matter here. The stop is when Claude reaches the safe point and Kiln tells it to start nothing more. The release comes after, once the session's processes have ended and its conversation is saved, so it is safe to resume or open in a terminal. Between pressing Pause now and the release, Kiln is pausing: the header says Pausing {activity}, and the panel says what Kiln is waiting for and that you can close your laptop, because the pause finishes on its own, even after the computer wakes from sleep.

Key acceptance criteria & mockups

  • The panel names what Kiln is waiting for: the command Claude is running, Claude's next command, a last check that nothing is still running, or a process Claude started that is still running. No terminal command appears until the pause completes. Source
  • Until the stop, Cancel pause and keep going withdraws the request, and the session carries on as if Pause now had not been pressed. From the stop on, Cancel is gone: wait for the pause, then press Resume. Cancelling never cancels a separate end-of-phase pause. Source

Offer Cancel pause in the browser only, with no command-line form?

Yes. Cancel pause and keep going is a browser button only, offered until the stop. The kiln take-over command, which starts a Pause now from the terminal, gets no matching cancel command.

A script or chat bot driving Kiln from the terminal that pauses by mistake waits for the pause to complete, usually within seconds, then resumes with the existing resume command, which reaches the same place.

If you choose otherwise: Kiln adds a terminal command that cancels a pending Pause now, and kiln status lists it with the other actions a script or bot can take.

Why this is proposed

Against: the pause after a phase already has a cancel command, and Kiln's terminal guide promises that everything the browser does with existing work can also be done from a terminal; a pause waiting on a long command, such as a test run, can last minutes. For browser only: the cancel window closes at the stop, which usually comes within seconds, resuming afterwards reaches the same place, you asked to keep pausing simple, and a command is easy to add later.

02 / SECTION

Choose when to pause

Under the live output of a running phase, or of an audit (Kiln's checking rounds after the phases), the pause panel offers two choices, told apart only by when Kiln stops. Whether you then resume or take the conversation over in your terminal is decided later, on the paused page, once you know which you want.

Key acceptance criteria & mockups

  • The panel, headed Pause, offers Pause now, which stops after the command Claude is running, and Pause after {phase or audit}, which lets it finish, commit and push first. There is no third pause; resuming or taking over is chosen after the pause. Source
  • Pause now is today's Pause & take over under a new name: the same safe stop that never interrupts a command, offered in the same situations. Everywhere Kiln names the action it says Pause now; the kiln take-over command keeps its name, so scripts that use it keep working. Source

03 / SECTION

Come back to a paused page

After the release, the activity reads Paused, in Kiln's neutral style rather than the amber Needs you, in the header, the phase plan and the terminal window running Kiln. The page says what Kiln stopped after and that nothing is running, then offers two equal ways on: let Kiln carry on in the same conversation, or open that conversation in your terminal and take it over.

Key acceptance criteria & mockups

  • Two equal columns: Let Kiln carry on, with an optional note for Claude and Resume, and Or take it over yourself, with the terminal command and Copy. On a phone, Let Kiln carry on comes first. Source
  • No completion checks, Check again or Mark complete: you paused it, so nothing failed. When you press Resume, Kiln first checks whether the phase is already done; if you finished it in the terminal, it offers to move to the next phase instead. Source

Replace today's reply card with an optional note on Resume?

Yes. Today's paused page has a separate card for typing a reply to Claude before it resumes. Instead, an optional Note for Claude box sits above Resume, and Resume sends whatever you type there first.

Details and optional reply

If Resume is refused, for example because Claude is still open in your terminal, the note stays unsent, as today's reply does.

If you choose otherwise: The paused page also shows today's “Reply here and let Kiln finish” card, or drops replying from this page altogether.

For: replying is something Kiln does today that you didn't ask to remove, and once you have paused, the running page's message box is gone. Against: the mockup you approved has no place to type to Claude, you described the page's choices as resume or take it over, and after a deliberate pause Claude hasn't asked anything.
