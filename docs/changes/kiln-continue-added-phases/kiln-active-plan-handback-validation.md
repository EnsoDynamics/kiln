## Durable contract

Private schema 12 adds `planReconciliation`, referencing immutable versioned `plans/<digest>.json` sidecars. The original document bytes, ordered parsed phases, comparison scopes, requirements manifest and known-source observations survive workspace loss. Completion references retain immutable revisions and repository identities for every checked repository, including externally completed work. Existing migration retains the original record bytes and older binaries reject schema 12. A failed observation preserves the accepted pointer and session receipts; the browser displays its recovery instruction. Sidecar bytes and directory metadata are flushed before the record points to them.

An unfinished legacy execution can establish its initial active baseline. Earlier Kiln-owned completions must first match their recorded immutable published phase documents; removed, reopened, split, materially changed or unavailable historical scope blocks acceptance. No earlier provider receipt is invented. New external Closed-only work must pass the ordinary active-workspace committed/published checks; an initially Closed phase can alternatively be proven at the exact clean, published setup base. A missing prior Kiln transcript is never converted to external completion. Completed-feature legacy-baseline recovery remains Phase 2 work.
