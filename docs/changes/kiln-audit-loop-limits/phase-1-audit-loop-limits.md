## Summary
Let the person set how many delivery and test audit loops Kiln makes on its own, stop at Needs you when a limit is reached with what the loops did and what is left, and let them allow more loops, take over, or accept what is left and deliver, from the page or the command line. A new PRD on Claude Code starts at Medium effort.
