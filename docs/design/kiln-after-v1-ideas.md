# Kiln future-feature index

The [Kiln roadmap](../kiln-roadmap.md) lists future feature ideas. Each idea below has a standalone note. This index retains the old headings so existing links continue to work.

## Run independent phases in parallel

## Computer-use preflight and Codex desktop handoff

## Review each phase before commit

[Let a person review staged phase work before authorizing its commit.](../roadmap/kiln-review-before-commit-idea.md)

## Merge the final PR

[Optionally carry final review PRs through checks and an authorized merge.](../roadmap/kiln-final-pull-request-merge-idea.md)

## Desktop app

[Provide a native wrapper and PRD-folder drag and drop.](../roadmap/kiln-desktop-app-idea.md)

## A "why it stopped" headline

[Generate a short explanation above the complete stop message.](../roadmap/kiln-stop-reason-headline-idea.md)

## A background service

[Keep controllers running without an attached terminal.](../roadmap/kiln-background-service-idea.md)

## Ubuntu live messages and safe terminal takeover

[Qualify live messages and safe takeover on Ubuntu, including remote tmux use.](../roadmap/kiln-ubuntu-live-control-idea.md)

## Notifications

[Notify the person when work needs attention or is ready for review.](../roadmap/kiln-system-notifications-idea.md)

## A home screen

[List and select PRDs from a browser or desktop entry screen.](../roadmap/kiln-prd-home-screen-idea.md)

## An end-of-PRD summary
